Contribute your notes

Got notes that could help others? Add them to the GitHub repo. You'll upload straight into Notes.

  1. Sign in to GitHub (it's free).
  2. Drag your files in and commit. GitHub will offer to fork the repo and open a pull request.
  3. Once your pull request is approved, your notes appear here.

The GitHub repo isn't set up yet. Add your username and repo name in config.js.
